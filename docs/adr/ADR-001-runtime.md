# ADR-001：标准库 HTTP/SQLite 与原生前端

状态：已采用；2026-11-17整理既有决策，原简述在docs/specification.md，不冒充事前记录。

背景：课程需要单机演示、固定证据与易复现环境。比较方案：Python标准库HTTP/SQLite；完整Web框架与数据库服务；只交命令行。

决定：保留现有标准库服务和原生前端，基础运行不引入框架；精确tokenizer为可选功能，完整测试安装其固定版本。成本是单机串行、多用户权限能力有限，不适合直接公网多租户。CLI评分与离线验收用于无模型环境交接。

触发重审：真实多用户隔离、持久并发队列或高吞吐需求。无需为了本课程材料补齐重写平台。
