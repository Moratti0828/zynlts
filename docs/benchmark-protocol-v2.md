## 评价对象和六个维度

测量“模型能否根据实际提供的陌生文本，恢复信息关系、整合证据、形成有依据的结论并识别信息不足”。关闭联网、检索、对话历史；固定权重、量化、提示词与输入预算。指标必须能对应具体操作，不能靠名称贴标签。

| 维度 | 要测的操作 | 出题验收条件 |
|---|---|---|
| D1 信息定位 | 找准主体、对象、时间、数量与范围 | 可直接从文中定位；直接摘取数字仍归 D1 |
| D2 语义理解 | 指代、否定、条件、例外、限定范围 | 交换主体、遗漏否定或错配时间能产生可辨别的错误 |
| D3 跨句整合 | 连接两个或多个必要信息单元 | 金标记录最短连接步骤；单句直接规则应用不充作跨句题 |
| D4 数量/时间推理 | 求差、比例、计数、排序、日期运算 | 记录操作数、运算、单位；答案不能只是摘文中的数字 |
| D5 主旨/结构/论证 | 理解作用与目的，检查论据支持范围 | 全局题保留充分文本；论证题的判断标准在文本/题面中；分别报告子类 |
| D6 信息边界 | 信息不足时拒答，同时避免误拒可答题 | 同主题缺条件或实体/时间/范围错配；明确被原文反驳的命题是可答判断 |

分类参考 [OECD 阅读框架](https://www.oecd.org/en/publications/pisa-2018-assessment-and-analytical-framework_b25efab8-en/full-report/component-3.html)，这六维是本项目定义，并非 OECD 官方六维量表或人类能力等级。[HotpotQA](https://aclanthology.org/D18-1259/) 提供支持事实评价思路；[DROP](https://aclanthology.org/N19-1246/) 强调离散运算；[SQuAD 2.0](https://aclanthology.org/P18-2124/) 提供接近可答题的无答案设计。

## 主指标和题型覆盖

新版分别报告选择题 Accuracy、短答 EM/token F1、数值及单位严格正确率、可答题段落证据集合 EM/Precision/Recall/F1，以及正确拒答率、无答案实质误答率和可答题误拒率。按语言及题型同时保留预定题数、文章数、有效输出和错误数量，不把没有样本的题型显示为满分或零分；没有适用题目时为 N/A。

短答严格正确依据冻结别名判定，F1 只作部分匹配；英文用词、中文用字符计数，属于项目明确指定的实现，不能称作 LongBench 官方中文分词分数。交换主体、遗漏否定或错配时间即使字词 F1 很高，也不能得到答案严格正确。数值题使用冻结单位、符号与容差。段落证据集合不是句级支持事实，不能直接混同 HotpotQA 的官方分数。

## 自定义联合指标及分母

**补充指标“有依据的理解成功率”：答案严格正确且完整证据集合正确。** 每题 `J=A×S`。A 通过冻结选项、明确短答案别名或数值/单位/容差判定；开放表达需要另行盲审，初版 v2 确定性评分器不伪装成语义裁判。S 使用预先审定的完整最小段落 ID 集合，可接受多套替代链；未知 ID、缺必要证据或多余无关证据均不得到严格成功。部分覆盖可另报集合 F1。

第一版用 **段落级**证据 ID。它不能叫句级 HotpotQA 分数，也不能证明内部推理。稳定 ID、实际段落文本、全文/节选范围、呈现文本 hash 一起冻结。合理但没列入金标的答案或替代证据链须在统一仲裁后更新全部模型，不能临时偏袒某个输出。

在每篇文章每维先平均 J，再对该维适用文章平均得 `U_d`；D1—D5 等权平均为 U。中英文分别计算；有任何维度未覆盖时 U 为 N/A，不能用已有维度冒充完整总分。双语总览只对两个完整语言分数等权平均。每维同时显示题数、文章数与区间；维度难度和覆盖不同，不能只凭分数断言某种能力天生更强。

**信息边界与 U 并列报告**：无答案正确拒答率 R、无答案实质误答率 H、可答题误拒率 F、可答题合法实质回答率 C；平衡准确率 `B=(R+C)/2`。C 表示愿意且合法回答，不表示答对。全部拒答和全部作答策略无执行错误时 B 都为 0.5；全部拒答的 U 为 0。失败不是正确拒答。

所有预定题进入成功分母。缺失、超时、契约错误成功项为 0，并另报错误率与有效输出覆盖。置信度契约是“答案正确概率”，Brier 的标签用 A，不能暗改为 J 或 F1。耗时、输出格式、Brier 与字词 F1 分开解释，不用于抵消理解错误。字词 F1 忽视次序与关键关系：[F1 is Not Enough!](https://aclanthology.org/2020.emnlp-main.575/) 讨论了这一类评价问题。

## 120 篇与 960 题的采编目标

| 项目 | 中文 | 英文 | 合计 |
|---|---:|---:|---:|
| 开发文章 | 10 | 10 | 20 |
| 隐藏测试文章 | 50 | 50 | 100 |
| 入选文章 | 60 | 60 | 120 |
| 候选题目标 | 480 | 480 | 960 |
| 隐藏测试题 | 400 | 400 | 800 |

六领域：科学技术、环境与能源、公共政策、社会与文化、健康与生命科学、经济与产业，各领域各语言 10 篇。每语言短/中/较长文本各 20；语言长度单位分别用汉字/词数，同时保存字符和实际 token 数。独立发布机构至少 8 个、单机构不超过全库 20%；机构下属部门和转载不能凭采集标签自动算独立来源。领域及体裁需按内容复核，不能直接用网站所属领域代替文章主题。

每篇目标 6 可答＋2 难无答案题。可答题至少 3 个维度、同维最多 3 题；不强求每篇都有计算或论证。正式 600 可答题目标 D1—D5 各 120 题、各语言各 60 题，每维覆盖至少 40 篇不同源文章。先填写文章-维度适用性矩阵，再按配额编题；不适用的维度补采正文，不能靠改标签凑数。

先收集至少 150 篇实际正文，保存原始响应、提取文本和元数据。原始候选→正文清理/重复与日期检查→按配额入选→具体问题/金标/证据编制→独立审题/仲裁→冻结。转载、同文翻译、节选、更新版和高度相似模板按源文章簇检查，不能跨开发/测试。这里的 120 是独立原文数，同一篇拆 10 个节选仍只算一篇。

优先 2026 年近期文章，首发下界 2025-01-01；每篇已知最早公开时间须晚于所有受试原始固定权重公开时间。网页发布日期证据有来源不等于全球首发已确认。未知旧稿、预印本和转载需待审，更新时间、URL、抓取时间不能代替首发。时间隔离降低公开文本泄漏风险；不能保证模型不知道旧事实或未经历后续微调。

## 标注格式、已完成实现与下一步

机器设计配置在 `data/benchmark-spec-v2.json`，详细方法审查在 `docs/benchmark-design-review.md`。平台“题库建设”可浏览已下载真实全文及 hash、日期证据、许可待核状态，与现有 8 篇/32 题的演示实验分开。

`data/annotation/dev-pilot-v2.json` 提供两篇真实近期文章的 **16 道具体开发候选题**：中文消费统计、英文航天科研。含两个定义的整合、求差、四项实验计数、限定日期、研究结论支持范围，以及同主题缺失信息题；不是统一替换关键词的模板。全部是 AI 核对、0 人工审题，不能作为正式模型排名金标。摘录完整段落，源索引、ID 与呈现文本 hash 留存。此类题还需复核选项强弱、所有替代证据和真正的测量难度。

v2 离线评分器已实现于 `backend/benchmark_v2.py`，可执行：

```bash
python scripts/score_benchmark_v2.py --bank data/annotation/dev-pilot-v2.json --responses data/annotation/dev-pilot-v2-scorer-fixture.json --model-ids constructed-scorer-fixture --allow-draft --output output/v2-scorer-diagnostic.json --bootstrap 2000
```

**该示例响应是构造的评分器输入，绝非真实模型输出。** `formal:false` 随报告保留；16 题正确参考输入验证评分器能按完整计划记账，不能说明模型会答。离线评分器接受 `answer`、`evidence_ids`、`abstain`、可选 `confidence`；数值题另有明确 `unit`。真实运行接口使用更严格的固定 JSON Schema，`answer`、`unit`、`evidence_ids`、`confidence`、`abstain` 五个字段全部必填，额外字段拒绝。提示词要求非数值题 `unit` 为空，拒答时答案、单位、证据为空；拒答一致性还由评分器核对。缺响应照样入计划分母，重复/未计划响应拒绝，旧 v1 导出不得偷偷改格式后称 v2 结果。未设置 `--allow-draft` 时，题库必须冻结并带两位不同审题者的接受记录和仲裁状态；代码只能检查记录结构，无法认证人员身份，不能自动生成审核签名。

关键检查已覆盖完整/缺失/替代证据链、交换主体、数值符号与单位、全拒/全答/失败策略、Brier 标签、正文 hash、草稿不能当正式。新版实验页已启用，按 `reading-experiment-v2` 契约真实调用并评分，历史 v1 实验仍可回查原 EM/引句重合 F1。创建新版实验时保存完整预定任务、题库和模型快照、评分器与 prompt 版本；取消、失败或中断后仅续跑尚未完成项，已有成功或错误结果不自动重试，版本或快照变化时拒绝续跑。完整 120 篇编题与人工审定均尚未完成，不能从下载数推导完成。

本次 Qwen 的 16 道双语开发题真实运行已完成，其中 3 个响应违反拒答一致性契约；这些失败保留原始输出并记零。当前两篇/16 题仍为 0 人工审题，不是正式金标，不能据此排出模型整体阅读能力名次。该批题没有短答样本，短答 EM/F1 应为 N/A；有数字、选择和信息不足题并不代表所有任务已完成真实验证。

正式比较采用相同文章题集的成对按源文章簇 bootstrap，按语言/领域/长度分层，2,000 次 seed 42。v2 实现分别给主任务指标、补充 U 及模型差值的区间，真实运行结束时按该次冻结配置计算；重采样没有适用题目或 U 缺维时报告有效次数，极少簇或极小分层的区间不能作总体结论。800 题不是 800 个独立样本，百篇也不保证能识别细小差异。旧 v1 实验不会被自动换算或重评分。

新版已采用 tokenizer/原生模板预算：本机 `qwen2.5:7b-instruct` 的固定 digest 与 `Qwen/Qwen2.5-7B-Instruct` 的冻结 revision `a09a35458c702b33eeacc393d103063234e8bc28` 匹配时，使用冻结模板生成完整输入，经 Ollama `raw:true` 接口原样发送并核对实际输入 token 计数。冻结文件保存在 `runtime/tokenizers/qwen25-7b-a09a354`，哈希清单和依赖版本随预算记录保留。上下文固定 8192 token，预算包含完整输入、最大输出和 512 token 余量，超限明确拒绝，禁止静默截断。

目前只完成上述 Qwen 固定版本的原生模板与实际计数核对，不能推广到所有模型。其他模型缺少匹配文件、依赖或模板认证时，严格预算拒绝运行；草稿模式可以使用明确标记的 UTF-8 字节上界加包装余量估算，不能据此宣称精确 token 预算。正式运行必须同时启用时间与精确预算门槛。旧 v1 保留 6000 UTF-8 字节/8192 上下文的限制。保存全文仍不代表能完整送入所有模型；较长正文需先检查各模型预算，必要时冻结清楚声明的节选。正式之前在开发集检查提示词与输出预算，不在隐藏测试上调规则。

## 工作量与阶段诚实

960 题是编题目标，需分批完成。结构化选项/数值＋证据 ID 可缩短复核时间，开放要点题更费工。先让真实审题人员试审 10—20 题，记录耗时和分歧率，再估算全库；不把 AI 核对当第二位人工。详细设计审查中的 6—10 分钟/人/题是保守排期假设，并不是课程必须投入的最低时间。

新版接口和已匹配 Qwen 的实际 tokenizer 预算已落地，平台演示与草稿诊断可真实执行。后续依次完成 20 篇开发文章筛选和正文/首发复核，分批编题并保持维度覆盖，核对其他受试模型的权重、tokenizer 与模板，完成全库 120 篇采编、真实独立审题和统一仲裁，冻结 100 篇隐藏测试集，最后运行相同题库的双语正式比较。具体顺序与验收见[后续调整计划](later-adjustment-plan-20261013.md)，结论须保持对应阶段。
