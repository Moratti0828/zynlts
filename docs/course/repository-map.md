# 仓库地图

| 课程类别 | 本仓库入口 |
|---|---|
| brief | Global.md、docs/course/problem-frame.md、docs/specification.md |
| design | docs/adr/、Harness.md、docs/course/state-model.md、impact-map.md |
| eval | tests/；scripts/verify_course.py |
| evidence | evidence/（本轮）；output/（历史逐题/成本/分析）；data/（题库/来源） |
| release | README.md、start.sh/start.ps1、deploy/ |
| review | review/peer-plan.md、review/findings.md、docs/experiments/ |
| 计划 | Plan.md、Tasks.md；task_plan.md为历史记录 |
| 实现 | backend/server.py、experiment_v2.py、benchmark_v2.py、live_demo.py；frontend/ |
