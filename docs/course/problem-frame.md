# 问题框架与需求

评测者面对不同模型的答案，难以判断分数是否来自相同材料、是否删掉失败、是否可回查。平台保存完整输入身份、逐题输出及确定性评分，使这些问题可以被核查。

使用者：课程作者、对抗组与教师。作者启动实验与解释结果；伙伴独立检验约定；教师裁决评分。最小路径：选开发题/模型 → 明确接受草稿状态 → 运行 → 查看回答/错误 → 导出。

范围与非目标见 Global.md；稳定规约见 docs/specification.md 及 acceptance-matrix.md。正式隐藏集尚未人审，是研究结论的阻塞项；不阻塞离线工程验收。

假设：金明源在提交时核查教师已接受本选题（目前未见独立开题批准记录）；用户已确认允许单人组。模型上线和对方仓库访问需在演示/结对前由本人核查，当前不假定可用。
